# A skill to help study engineering in hard times.

This is a claude skill that I made for learning any technical course topic from absolute zero(it will even teach you the prerequisites). Built for exam prep when a course comes with no slides or is low on sources.

---

## The flow:

```
Checks prerequisites ---> overview with the core "why" questions
        ↓
In-depth explanation with diagrams, math and relations between topics
        ↓
Short practice you solve yourself ---> answers checked
        ↓
Review, cheat sheet and cross-topic exam questions on request
```

---

## Install on claude.ai:

1. Download `engineering-study-skill.zip`.
2. Open Settings, then Skills (under Capabilities or Features, depending on the version).
3. Upload the zip and turn the skill on.


---

## Use:

<!-- Just start studying, for example: "teach me X from zero for my exam". You can also type: -->

type `/engineering-study-skill` then ask what you want to learn, let claude do the rest!

```
let's go or go  :  goes to next module
review          :  reviews the module or the whole session
practice        :  gives examples and answers  
deepen X        :  goes deeper in that topic  
exam questions  :  tries to generate exam-like questions based on what you have provided
```
